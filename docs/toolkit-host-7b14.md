## 验收边界与剩余风险

本阶段完成源码层功能修复和隔离 macOS Host 联调，**不宣称真实 Claude 账户或 VPS 的端到端生产可用验收已经完成**。没有提供独立非生产账户/远程环境；未读取真实凭证、修改真实账户或连接生产 VPS。真实窗口使用 production main/preload/panel，但根据仓库规则隐藏运行，不抢占桌面焦点；本地 electron skill 不存在，使用仓库已有 Playwright/CDP 方法。

临时测试中的 Host admission/服务身份、远程 RPC、SSH range 网络、文件选择和确认答案均明确模拟；本地文件系统、1 GiB 文件校验、SSH 签名、回执验证、SQLite 状态和 Electron 进程恢复真实执行。真实网络长时间中断、真实配额/过期凭证、物理磁盘耗尽、TCC 系统弹窗、Finder 可见窗口、完整安装包 admission/enrollment 仍待独立验收。重启重算全部历史成品的 SHA-256 会增加首次任务加载时间；大规模下载历史的性能仍需后续实测。运行中账户变化由现有会话保留各自身份；这不是会话迁移功能。
