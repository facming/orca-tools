ComfyUI on Mac

Use the local manager to start or stop managed ComfyUI. Custom nodes and API nodes are disabled. Godot requires a locally approved installation and project. Project scripts run with your user permissions; they are not sandboxed. ComfyUI, Godot and Blender are managed independently. Blender requires a locally selected installation; Metal is checked per render and may fall back to CPU.
